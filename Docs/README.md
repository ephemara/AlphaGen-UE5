# AlphaGen

Professional alpha texture generation toolkit for Unreal Engine.

## What It Does

AlphaGen lets you create alpha/mask textures directly in the editor using procedural generators and GPU-accelerated compute - with realtime preview! No external tools needed.

## How to Use

1. Open the AlphaGen window from the toolbar (look for the AlphaGen icon above the viewport)
2. Choose a generator type (Perlin Noise, Voronoi, Gradient, etc.)
3. Adjust parameters in real-time
4. Select export resolution (up to 8k!)
5. Export to your project or save to disk

## Features

- Procedural Generators: Perlin noise, Voronoi cells, gradients, and more
- GPU Compute: Fast generation and filtering using compute shaders
- Filter Chain: Stack multiple filters for complex effects
- Live Preview: See changes instantly
- Export Options: Save to project Content Browser or export as PNG

## System Requirements

- Unreal Engine 5.4 or later
- Windows, Mac, or Linux
- GPU with compute shader support

## Quick Start

Generate a noise texture:
1. Open AlphaGen window
2. Select "Perlin Noise" generator
3. Set texture size (512, 1024, 2048, or 4096)
4. Adjust frequency and octaves
5. Click "Export to Project" to save it
